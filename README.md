# Chinese-Idiom-Chain-Game

**中文成語接龍遊戲（CICG）**是一款大字體、離線優先、可安裝至手機主畫面的繁體中文成語接龍 PWA。

## 已完成

- React + TypeScript + Vite PWA 基礎。
- 離線成語字典、CSV 驗證、首尾字索引與 SHA-256 校驗。
- 經典接龍：判定、重複防護、計分、連擊、提示與自然結束。
- Android／Chromium 安裝提示與 iPhone／iPad 加入主畫面教學。
- 成語打地鼠獎勵關卡：能量槽、自選獎勵、15 秒補最後一字、6／9 洞位、鍵盤 1～9。
- 提示券、失誤護盾、雙倍分數，以及後續限時模式可使用的加時資源。
- 四級打地鼠難度、單題自動輪替、背景暫停與一次性結算防護。

## 尚未實作或仍待正式驗證

- 60 秒限時模式與選擇題模式。
- 生命值、設定頁、成語小冊、發音輔助與 IndexedDB 成績。
- Lighthouse、瀏覽器 E2E、Android／iOS 實機與完整離線 PWA 驗收。

## 經典接龍規則

- 下一個成語第一字必須等於目前成語最後一字。
- 僅接受本機字典內已啟用的四字成語。
- 同一局不能重複使用相同成語。
- 正確答案基礎分 100；連擊每次增加 20，上限加成 200。
- 沒有提示券時，使用提示扣 50 分，分數最低為 0。
- 護盾會在答錯時消耗一層並保留連擊。
- 雙倍分數依剩餘題數套用，不重複相加。

## 成語打地鼠

### 能量

| 條件 | 能量 |
|---|---:|
| 一般答對 | +15% |
| 連擊達 3 題 | 額外 +5% |
| 連擊達 5 題以上 | 再額外 +10% |
| 困難成語 | 額外 +5% |
| 使用提示後答對 | 僅取得基本 +15% |

- 能量最高 100%，滿格後由玩家自行啟動。
- 離開獎勵選擇畫面不扣能量。
- 可用安全題目少於 8 題時禁止啟動，能量保持不變。
- 主線過關後最多攜帶 50% 能量至下一關。

### 經典模式獎勵

- **提示券**：下一次提示優先免費使用。
- **雙倍分數**：下一批正確答案取得 2 倍分數。
- **失誤護盾**：答錯時保留連擊。

### 操作與難度

- 題目採「補最後一字」，每題 4 個安全候選字。
- 手機 6 洞；寬度至少 768px 時為 9 洞。
- 支援觸控、滑鼠、數字鍵 `1`～`9`。
- 單題依難度每 1.5～2.5 秒自動輪替。
- 第一次切到背景暫停；第二次切到背景視為放棄本輪。

| 難度 | 單題時間 | 打錯處罰 |
|---|---:|---|
| 輕鬆 | 2.5 秒 | 扣 20 分，保留連擊 |
| 標準 | 2.0 秒 | 扣 50 分，連擊歸零 |
| 挑戰 | 1.7 秒 | 扣 50 分並減少 1 秒 |
| 極限 | 1.5 秒 | 減少 1 秒，連擊歸零 |

## 架構

```text
src/domain       領域型別與契約
src/idioms       字典索引與載入
src/game         經典接龍引擎
src/game/bonus   能量、出題、回合與獎勵引擎
src/app          React UI 與瀏覽器事件 Hook
src/pwa          PWA 安裝與裝置判斷
```

規則維持純 TypeScript；React 只呈現狀態並傳送玩家操作。
