# CICG 成語卡牌標準模板 v2.1 版面增補

- 狀態：Approved
- 日期：2026-08-06
- 適用範圍：所有成語卡牌模板、單卡提示語、產圖審核與 Drive 核准素材
- 優先級：本增補與 `docs/card-prompts/shared/card-master-prompt.md` 優先於較早的卡牌提示語描述

## 1. 主標題與注音

- 主標題固定為四字繁體中文成語。
- 每一個國字旁必須配置對應的直立注音符號，由上到下排列並逐字對齊。
- 不得顯示漢語拼音、英文拼音或任何羅馬字母拼音。
- 注音可以小於國字，但必須在手機尺寸仍可辨識。

## 2. 典故區

- 下方內容區標題只使用「典故」。
- 不得顯示「典故說明」四字標籤。
- 典故摘要保持精簡，避免壓縮中央主插圖。
- 最下方保留單行極小字的典故來源。

## 3. 主題徽章

- 左下主題徽章必須保留。
- 固定呈現類別圖示、固定底色與完整繁體中文類別名稱。
- 主題徽章不因稀有度改色。

## 4. 卡牌箴言

- 右下使用獨立窄版深色金框牌匾。
- 繁體中文直式排版，由右至左分欄閱讀。
- 文案短促有氣勢，通常三句，每句約四至六字並保留標點。
- 牌匾高度必須下降並貼合實際文字，不得向上拉高形成大面積留白。
- 不得使用橫式長段落，也不得過度遮蔽中央主插圖。

## 5. 稀有度

- 稀有度與成語難易度是兩套獨立系統。
- 稀有度依成語的正面意義、激勵強度、人格力量與收藏定位判定。
- `SSR` 優先保留給強烈展現堅持、勇氣、突破、成就或正向精神的成語，例如「愚公移山」與「破釜沉舟」。
- 警世、負面行為、恐懼或侷限型成語不得只因知名度高就標成 SSR。
- `UR` 僅預留經正式授權的 IP 聯名隱藏版本；沒有授權文件時不得產生 UR 卡牌或聯名識別。

## 6. 審核 Gate

正式核准前必須確認：

- [ ] 四字成語與逐字直立注音正確。
- [ ] 完全沒有羅馬拼音。
- [ ] 典故區沒有「典故說明」標籤。
- [ ] 左下主題徽章完整保留。
- [ ] 右下箴言牌匾高度貼合文字且沒有大面積空白。
- [ ] 稀有度已依正面意義標準人工核准。
- [ ] UR 若存在，具備正式 IP 授權與核准證據。
- [ ] 典故來源、繁體文字、注音、解釋與例句完成校訂。
