# CICG 成語卡牌標準模板 v2.1 版面增補

- 狀態：Approved historical baseline
- 日期：2026-08-06
- 適用範圍：舊版成語卡牌模板、單卡提示語、歷史產圖審核與 Drive 舊素材
- 優先級：本文件中未被覆寫的典故區、主題徽章與箴言規則仍有效

> **重要：** `2026-08-06-card-template-v2.6-dimension-and-pronunciation-amendment.md` 已覆寫本文件的尺寸、比例、注音位置與禁止羅馬拼音條款。新產圖不得再依本文件使用 `2:3`、`1024 × 1536`、側邊直立注音或無拼音版面。

## 1. 主標題與注音（歷史規則）

- 主標題固定為四字繁體中文成語。
- 本節原本規定每一國字旁配置直立注音，現已由 v2.6 覆寫。
- v2.6 改為：主標下方第一列為四組逐字對齊注音，第二列為小寫、帶聲調漢語拼音。

## 2. 典故區（保持有效）

- 下方內容區標題只使用「典故」。
- 不得顯示「典故說明」四字標籤。
- 典故摘要保持精簡，避免壓縮中央主插圖。
- 最下方保留單行極小字的典故來源。

## 3. 主題徽章（保持有效）

- 左下主題徽章必須保留。
- 固定呈現類別圖示、固定底色與完整繁體中文類別名稱。
- 主題徽章不因稀有度改色。

## 4. 卡牌箴言（保持有效）

- 右下使用獨立窄版深色金框牌匾。
- 繁體中文直式排版，由右至左分欄閱讀。
- 文案短促有氣勢，通常三句，每句約四至六字並保留標點。
- 牌匾高度必須下降並貼合實際文字，不得向上拉高形成大面積留白。
- 不得使用橫式長段落，也不得過度遮蔽中央主插圖。
- v2.6 另要求牌匾不得侵入 `y = 360–1559` 的 1200 px 中央主圖區。

## 5. 稀有度（保持有效）

- 稀有度與成語難易度是兩套獨立系統。
- 稀有度依成語的正面意義、激勵強度、人格力量與收藏定位判定。
- `SSR` 優先保留給強烈展現堅持、勇氣、突破、成就或正向精神的成語，例如「愚公移山」與「破釜沉舟」。
- 警世、負面行為、恐懼或侷限型成語不得只因知名度高就標成 SSR。
- `UR` 僅預留經正式授權的 IP 聯名隱藏版本；沒有授權文件時不得產生 UR 卡牌或聯名識別。

## 6. 現行審核入口

新產圖必須改用 v2.6 Gate：

```text
尺寸：1024 × 2000 px
上方資訊區：360 px
中央主圖區：1200 px
下方內容區：440 px
主標下方：注音橫列
注音下方：帶聲調漢語拼音橫列
```

本文件只作為歷史基礎與未被覆寫規則的來源。
