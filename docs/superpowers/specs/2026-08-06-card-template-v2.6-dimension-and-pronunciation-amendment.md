# CICG 成語卡牌標準模板 v2.6 尺寸與發音版面增補

- 狀態：Approved
- 日期：2026-08-06
- 適用範圍：所有成語卡牌模板、單卡提示語、圖片產製、Drive 核准素材與圖卡審核
- 核准來源：使用者於專案對話明確指定此版型為標準模板
- 規範類型：既有圖卡版面增補；不包含 production code 或進度 Schema 修改

## 1. 覆寫範圍

本文件只覆寫下列既有規則：

1. `2026-08-06-card-template-v2.1-layout-amendment.md` 的直式 `2:3` 與 `1024 × 1536` 建議尺寸。
2. 舊版「禁止漢語拼音／羅馬拼音」規則。
3. 舊版逐字直立注音配置。

其餘稀有度、難易度、UR 授權、典故來源、人物情境、主題徽章、箴言與審核治理規則保持有效。

發生衝突時，以本 v2.6 增補為準。

## 2. 固定輸出尺寸

正式 v2.6 卡牌圖片固定為：

```text
寬度：1024 px
高度：2000 px
格式：PNG
色彩：RGB 或 RGBA；不得有透明破損
```

永久 Gate：

```text
canvas.width === 1024
canvas.height === 2000
```

不得把正式 v2.6 圖卡輸出成 `1024 × 1536`、`2:3` 或任意比例後僅以檔名宣稱符合 v2.6。

## 3. 固定版面座標

以左上角為 `(0, 0)`，Y 軸向下：

| 區塊 | Y 座標 | 高度 | 用途 |
|---|---:|---:|---|
| 上方資訊區 | `0–359` | `360 px` | 稀有度、主標、注音、拼音、副標、難易度 |
| 中央主圖區 | `360–1559` | `1200 px` | 人物情境主插圖 |
| 下方內容區 | `1560–1999` | `440 px` | 主題徽章、典故、箴言、典故來源 |

總高度驗算：

```text
360 + 1200 + 440 = 2000 px
```

中央主圖區必須是實際 `1200 px` 高的獨立版面區塊，不得只以視覺拉伸或提示語描述代替座標驗證。

## 4. 上方資訊區

固定順序：

1. 左上稀有度徽章：`N / R / SR / SSR`。
2. 上方中央四字繁體中文成語主標。
3. 主標正下方第一列：四組注音符號，每組對齊對應國字。
4. 注音正下方第二列：漢語拼音羅馬字。
5. 拼音下方：一句精簡白話副標。
6. 右上：只顯示「難易度」與 `E / D / C / B / A / S`。

### 4.1 注音列

- 注音改為主標下方的單一橫列，不再放在國字側邊。
- 四組注音必須依四字順序排列並與國字欄位水平對齊。
- 使用教育部標準注音符號與聲調。

例：

```text
ㄩˊ　ㄍㄨㄥ　ㄧˊ　ㄕㄢ
```

### 4.2 羅馬拼音列

- 使用現代標準漢語拼音。
- 使用小寫字母與聲調符號。
- 四個音節依成語順序排列。
- 禁止用數字聲調，例如 `yu2 gong1 yi2 shan1`。
- 禁止省略聲調符號作為正式核准版本。

例：

```text
yú gōng yí shān
```

## 5. 中央主圖區

- 固定座標：`x = 0–1023`、`y = 360–1559`。
- 固定高度：`1200 px`。
- 主插圖必須占卡面最大面積。
- 至少一名人物以動作、表情、道具與場景直接表達成語。
- 不得把人物只畫成與成語無關的站立肖像。
- 不得以放大裁切造成主要人物、手部、道具或關鍵情境被切除。

## 6. 下方內容區

固定座標：`y = 1560–1999`，高度 `440 px`。

必須保留：

- 左下主題徽章與完整類別名稱。
- 中下方「典故」標題與精簡摘要。
- 右下窄版深色金框直式箴言牌匾，由右至左閱讀。
- 最下方單行小字典故來源。

箴言牌匾不得向上侵入中央主圖區形成大面積遮擋。

正式或送審圖卡至少檢查：

```text

[ ] 上方資訊區恰為 360 px
[ ] 中央主圖區恰為 1200 px
[ ] 下方內容區恰為 440 px
[ ] 四字繁體中文主標正確
[ ] 注音位於主標下方第一列並逐字對齊
[ ] 拼音位於注音下方第二列
[ ] 拼音使用小寫與聲調符號
[ ] 左上稀有度與右上難易度分離
[ ] 下方只標「典故」
[ ] 左下主題徽章完整
[ ] 右下箴言為窄版直式牌匾
[ ] 典故來源位於最下方單行
```

任一 Blocking Gate 失敗時，只能標記為 `Review` 或 `Changes Requested`。

## 10. 不變規則

- 稀有度與難易度仍是兩套獨立系統。
- N～SSR 仍依成語正面意義、勵志程度、精神象徵、共鳴力與代表性判定。
- UR 仍只保留給具有可稽核正式授權的外部 IP 聯名。
- 未校訂來源、權利不清或未通過審核的單卡不得進入正式卡池。
- 本次不修改主玩法、關卡、IndexedDB 進度 Schema、卡池演算法或付款功能。
