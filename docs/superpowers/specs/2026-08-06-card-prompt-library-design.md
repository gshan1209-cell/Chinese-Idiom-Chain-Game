# 成語圖卡提示語素材庫設計規格

- 狀態：Approved for implementation
- 日期：2026-08-06
- 適用專案：Chinese-Idiom-Chain-Game
- 對應卡牌規範：CICG 成語卡牌標準模板 v2.1

## 1. 目的

建立可重複產圖、可審核、可版本追蹤的成語圖卡提示語素材庫，使每張既有圖卡都有一份獨立提示語文件，並以總索引統一管理 GitHub 文案與 Google Drive 圖片素材。

## 2. 儲存分工

### GitHub

存放可版本控制的文字資產：

- 每張成語圖卡的獨立 Markdown 提示語
- 四種稀有度模板提示語
- 共用母提示語與負面限制
- 圖卡提示語總索引 Manifest
- Drive 圖片連結與素材狀態

建議路徑：

```text
docs/card-prompts/
├─ README.md
├─ manifest.md
├─ shared/
│  ├─ card-master-prompt.md
│  └─ negative-constraints.md
├─ templates/
│  ├─ CICG_CardTemplate_Rarity_N_v2.1_Prompt.md
│  ├─ CICG_CardTemplate_Rarity_R_v2.1_Prompt.md
│  ├─ CICG_CardTemplate_Rarity_SR_v2.1_Prompt.md
│  └─ CICG_CardTemplate_Rarity_SSR_v2.1_Prompt.md
└─ idioms/
   └─ CICG_IdiomCard_<成語>_<稀有度>_<難易度>_v2.1_Prompt.md
```

### Google Drive

存放圖片與素材備份：

```text
02_UI_UX_And_Visuals/
├─ CICG_Card_Templates_v2.1_Approved/
├─ CICG_Idiom_Cards_v2.1_Approved/
└─ CICG_Legacy_Card_Assets_Backup/
```

既有圖卡與未核准舊版可作素材備用，但不得直接視為正式 v2.1 成品。

## 4. 每張提示語文件固定欄位

每份 Markdown 必須包含：

1. 基本資料
   - 成語
   - 稀有度
   - 難易度
   - 主題徽章
   - 主題色
   - 主角配置
2. 典故查核
   - 標準含義
   - 典故時代
   - 人物與場景
   - 來源格式
   - 史實、寓言、傳說或泛用比喻
3. 卡面文案
   - 成語標題
   - 白話副標
   - 典故摘要
   - 卡牌箴言
   - 典故來源
4. 視覺構圖
   - 主角性別與動作
   - 配角與環境
   - 鏡位、光影與敘事重點
   - 左下主題徽章
5. 正式產圖提示語
6. 負面限制
7. 驗收清單
8. 素材連結
   - Drive 圖片 URL 或 File ID
   - 圖片狀態：Legacy / Review / Approved

## 5. 共用卡牌母提示語

所有卡牌共用以下不可變規則：

- 直式 2:3。
- 高質感韓日動漫遊戲卡牌風格。
- 繁體中文。
- 主插圖至少有一名人物，且必須透過動作、表情、道具與環境表達成語。
- 外框使用同一系列固定深色金框，不隨 N、R、SR、SSR 改色。
- 左上為稀有度徽章；只有徽章內的字體、底色、材質與局部光效依稀有度改變。
- 稀有度固定為 N、R、SR、SSR。
- 稀有度徽章配色：N 灰鐵、R 藍色、SR 紫金、SSR 虹彩金。
- SSR 稀有度徽章字樣可採較強烈的手寫或筆觸感；不得讓整張卡外框或主圖跟著染色。
- 右上只顯示「難易度」與 E、D、C、B、A、S 等級字母，不得顯示「人氣」。
- 左下主題徽章使用固定類別圖示、底色與名稱；不受稀有度影響。
- 主題徽章下方必須顯示完整類別名稱。
- 右下為窄版深色金框直式箴言牌匾，由右至左閱讀，原則上三句。
- 最下方顯示單行小字來源：`典故來源：朝代・作者《典籍名稱・卷次》`。
- 角色配置依題材決定，不強制每批男女各半，但不得長期將無明確性別限制的題材全部預設為男性。

## 7. 負面限制

每份提示語至少包含以下限制：

- 不得使用簡體中文。
- 不得把稀有度色套用到外框或主插圖。
- 不得把左下主題徽章改成稀有度顏色。
- 不得出現「人氣」。
- 不得省略主題徽章下方類別名稱。
- 不得使用與典故矛盾的朝代、人物、服飾或道具。
- 不得將原創箴言冒充古籍原文。
- 不得把人物畫成單純正面站立肖像。
- 不得複製參考遊戲的美術、文案、關卡或商店素材。

## 8. Manifest 欄位

總索引每列至少包含：

| 欄位 | 說明 |
|---|---|
| idiom | 成語 |
| rarity | N / R / SR / SSR |
| difficulty | E / D / C / B / A / S |
| themeCategory | 主題類別英文值 |
| themeLabel | 主題類別繁體中文 |
| leadCharacter | 主角配置 |
| promptPath | GitHub 提示語檔案路徑 |
| driveImageUrl | Drive 圖片連結 |
| assetStatus | Legacy / Review / Approved |
| sourceStatus | Verified / NeedsReview |
| notes | 重製或文字校訂備註 |

## 9. 驗收標準

- 22 張既有成語圖卡皆有獨立提示語文件。
- 4 張稀有度模板皆有獨立提示語文件。
- 所有提示語均引用共用母規則，且自身資訊完整。
- Manifest 可一眼查到成語、稀有度、難易度、分類、角色、文件與 Drive 素材。
- 所有既有圖片均標示為 Legacy、Review 或 Approved，不以舊圖冒充 v2.1 正式成品。
- 未完成來源校訂的成語標記 `NeedsReview`，不得宣稱已正式授權或完成典故校訂。

## 10. 非目標

- 本階段不重新產製 22 張正式成語圖卡。
- 本階段不修改遊戲程式與資料 schema。
- 本階段不把圖片二進位檔納入 GitHub。
- 本階段不處理正式授權文件與商店上架素材。
