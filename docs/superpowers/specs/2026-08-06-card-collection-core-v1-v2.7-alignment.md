# 收藏資料核心 v1 與 v2.7 SSR 徽章對齊紀錄

日期：2026-08-06

v2.7 只覆寫 SSR 左上稀有度徽章視覺，不改變收藏資料核心的里程碑、交易、發音、授權或卡池規則。

資料核心適用結果：

- `rarity === 'SSR'` 的正式卡仍必須通過 `approvalStatus === 'Approved'`、`sourceStatus === 'Approved'` 與 `rarityApproved === true`。
- SSR 圖卡素材只有在 v2.7 徽章審核通過後，才能被標記為 Approved 並進入一般里程碑卡池。
- v2.7 不改變 N／R／SR／SSR 的語義稀有度判定。
- UR 仍只保留給具可稽核正式授權的 IP 聯名，且不進一般十關里程碑卡池。
- 首版正式卡池仍為空，不因 v2.7 模板或徽章素材核准而自動產生可發放卡片。
