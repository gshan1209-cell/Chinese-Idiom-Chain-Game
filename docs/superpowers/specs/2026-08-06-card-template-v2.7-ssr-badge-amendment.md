## 2. SSR 徽章正式設計

SSR 左上徽章採「傳奇級虹彩金龍徽章」：

- 金龍以較完整的環抱式構圖包覆 SSR 字樣。
- SSR 使用大尺寸立體金字，字緣帶暖金高光與深色陰影。
- 徽章核心使用紫、藍、洋紅的星雲寶石光，形成明確的虹彩層次。
- 徽章下端使用紫色菱形寶石作為視覺錨點。
- 外圍增加金色火焰、羽翼或流線雕紋，但不得侵占成語主標的主要閱讀區。
- SSR 徽章必須一眼明顯高於 SR 的紫金圓章，不得只把 SR 改成三個字母。

## 3. 與其他稀有度的區隔

| 稀有度 | 左上徽章定位 |
|---|---|
| N | 灰鐵／低彩度基礎徽章 |
| R | 藍銀／清晰寶石光徽章 |
| SR | 紫金／高級圓章或龍紋徽章 |
| SSR | 傳奇級虹彩金龍、立體金字、星雲寶石核心與紫色主寶石 |

永久 Gate：

- SSR 徽章必須與 SR 在輪廓、材質、光效與主寶石四方面都有可辨識差異。
- 不得只增加亮度、飽和度或特效數量就宣稱完成 SSR 升級。
- 稀有度徽章的華麗度不能反向決定成語語義稀有度。
- 外框、難易度框、中央主圖、典故區、主題徽章與箴言牌匾仍不得因 SSR 全面染成虹彩。
