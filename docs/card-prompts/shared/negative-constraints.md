# CICG 成語卡牌共用負面限制 v2.7／Modular v1.0

## Modular source 禁止事項

- 不得把卡框、稀有度、難易度、主標、注音、拼音、副標、主題徽章、典故、箴言或來源永久烙入 canonical artwork。
- 不得只保存 final flat PNG 而遺失 artwork、component 與 structured data。
- 不得修改難易度、稀有度徽章或文字時重畫合格 artwork。
- 不得在替換元件時改變 `artworkAssetId`、artwork version 或 artwork SHA-256。
- 不得把 Review／Approved composite PNG 描述為唯一 canonical source。
- 不得把 renderer 尚未完成當成退回 flat canonical workflow 的理由。
- 不得把舊平面圖裁切後未經品質驗證就宣稱為 canonical artwork。
- 不得將未核准 Drive master 打包進正式 PWA runtime assets。
- 不得混用 artwork 與 composite 的 Drive File ID、SHA-256 或審核狀態。

## Composite 尺寸與版面

- 不得使用 `1024 × 1536`、`2:3` 或其他尺寸宣稱符合目前標準。
- 不得讓上方資訊區不是 `360 px`。
- 不得讓中央主圖區不是 `1200 px`。
- 不得讓下方內容區不是 `440 px`。
- 不得把注音放在國字側邊；目前注音必須是主標下方第一列。
- 不得省略四字逐字對齊的注音橫列。
- 不得省略注音下方的漢語拼音橫列。
- 不得使用數字聲調，例如 `yu2 gong1 yi2 shan1`。
- 不得在正式核准版本省略拼音聲調符號。
- 不得把拼音放在注音上方。
- 不得出現「人氣」。

## 稀有度與元件

- 不得讓稀有度色系染到外框或主插圖。
- 不得讓稀有度改變難易度框、典故區、箴言牌匾或左下主題徽章。
- 不得以成語難易度、知名度、人氣或畫面華麗程度直接決定稀有度。
- 不得把警世、負面行為或侷限型成語只因知名度高就標成 SSR。
- 未取得正式 IP 授權時不得使用 `UR`、聯名角色、品牌名稱或聯名識別。
- 不得把 v2.7 SSR 傳奇金龍徽章用於 N／R／SR。
- 不得讓 SSR 只比 SR 多一個字母、亮度或飽和度。
- 不得把 SSR 虹彩色系套用到整張卡面。
- 不得改變主題徽章的固定圖示、固定底色或類別名稱。
- 不得省略主題徽章下方的完整類別名稱。

## 內容、品質與權利

- 不得使用簡體中文。
- 不得顯示「典故說明」四字標籤；下方區塊只使用「典故」。
- 不得把右下箴言牌匾拉高形成大面積空白，也不得讓牌匾過度遮住主插圖。
- 不得使用與典故矛盾的朝代、人物、服飾、建築或道具。
- 不得把原創箴言、白話摘要或後世改寫冒充古籍原文。
- 不得把人物畫成缺乏動作與情境的靜態正面肖像。
- 不得複製參考遊戲的美術、角色、文案、關卡或商店素材。
- 不得塞入無關 Logo、浮水印、現代品牌、廣告標語或介面按鈕。
- 不得讓裝飾壓過成語標題、主要人物、典故與來源文字。
- 未完成來源、注音或拼音校訂時，不得標示 `Verified`、已授權或可正式發布。
- 未完成稀有度人工複核時，不得宣稱卡牌已具正式稀有度或可進入正式卡池。
- 產製 Agent 不得自行把自己的 artwork 或 composite 標記為最終 Approved。
