# CICG 成語卡牌共用負面限制 v2.1

- 不得使用簡體中文。
- 不得省略四字成語旁逐字對齊的直立注音。
- 不得顯示漢語拼音、英文字母拼音或其他羅馬拼音。
- 不得出現「人氣」。
- 不得讓稀有度色系染到外框或主插圖。
- 不得讓稀有度改變難易度框、典故區、箴言牌匾或左下主題徽章。
- 不得以成語難易度、知名度、人氣或畫面華麗程度直接決定稀有度。
- 不得把警世、負面行為或侷限型成語只因知名度高就標成 SSR。
- 未取得正式 IP 授權時不得使用 `UR`、聯名角色、品牌名稱或聯名識別。
- 不得改變主題徽章的固定圖示、固定底色或類別名稱。
- 不得省略主題徽章下方的完整類別名稱。
- 不得顯示「典故說明」四字標籤；下方區塊只使用「典故」。
- 不得把右下箴言牌匾拉高形成大面積空白，也不得讓牌匾過度遮住主插圖。
- 不得使用與典故矛盾的朝代、人物、服飾、建築或道具。
- 不得把原創箴言、白話摘要或後世改寫冒充古籍原文。
- 不得把人物畫成缺乏動作與情境的靜態正面肖像。
- 不得複製參考遊戲的美術、角色、文案、關卡或商店素材。
- 不得塞入無關 Logo、浮水印、現代品牌、廣告標語或介面按鈕。
- 不得讓裝飾壓過成語標題、主要人物、典故與來源文字。
- 未完成來源校訂時，不得標示 `Verified`、已授權或可正式發布。
- 未完成稀有度人工複核時，不得宣稱卡牌已具正式稀有度或可進入正式卡池。
