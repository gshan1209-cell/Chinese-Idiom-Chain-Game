## 卡面文案
- 成語標題：掩耳盜鈴
- 白話副標：遮住自己，遮不住事實
- 典故摘要：偷鐘的人怕鐘聲引來旁人，便掩住自己的耳朵再拉動大鐘，以為自己聽不見就無人聽見。
- 卡牌箴言：自欺無益，／真相有聲，／莫掩人目。
- 典故來源：典故來源：戰國・呂不韋編《呂氏春秋・自知》

## 視覺構圖
女性竊賊一手緊掩雙耳、一手拉動古鐘繩，巨鐘震動產生可視聲浪；院外居民與守衛同時回頭。近景動作構圖。左下固定靛紫色警世徽章。

## 正式產圖提示語
生成直式 2:3 繁體中文 CICG 卡牌「掩耳盜鈴」。固定深色金框；左上藍色 R 稀有度徽章只影響徽章；右上只顯示「難易度」與 C。中央畫面呈現女性竊賊掩耳拉鐘、鐘聲波紋擴散、旁人回頭的明確矛盾。左下固定靛紫色 `#3F2B78` 警世徽章與「警世」文字。下方典故區放入摘要；右下直式箴言「自欺無益，／真相有聲，／莫掩人目。」最下方顯示來源。外框、主圖與類別徽章不得隨 R 改色。
