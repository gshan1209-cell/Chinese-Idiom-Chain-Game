## 卡面文案
- 成語標題：自相矛盾
- 白話副標：前後衝突，再華麗也站不住腳
- 典故摘要：商販誇口盾無物可破，又說矛無物不穿；有人問用矛刺盾會如何，她便無法回答。
- 卡牌箴言：言須一致，／理要相容，／莫自相攻。
- 典故來源：典故來源：戰國・韓非《韓非子・難一》

## 視覺構圖
女性商販站在市集中，一手高舉鋒利長矛、一手展示厚重盾牌；圍觀者提出疑問，她神情僵住。矛尖直指盾面形成張力。左下固定靛紫色警世徽章。

## 正式產圖提示語
生成直式 2:3 繁體中文 CICG 卡牌「自相矛盾」。固定深色金框；左上 SR 稀有度只影響徽章；右上只顯示「難易度」與 C。中央呈現女性商販同時誇耀矛與盾，圍觀者質問、矛尖對準盾面、商販語塞的瞬間。左下固定靛紫色 `#3F2B78` 警世徽章，下方顯示「警世」。典故區放摘要；右下直式箴言「言須一致，／理要相容，／莫自相攻。」最下方顯示來源。外框、主圖與類別徽章不得隨 SR 改色。
